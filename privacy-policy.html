ТЕМА: Политика конфиденциальности и защиты персональных данных

I. Цель документа

А. Настоящая Политика конфиденциальности определяет:

  • Порядок сбора персональных данных
  • Цели обработки информации
  • Меры защиты персональных данных пользователей

Б. Основные принципы:

  • Законность обработки персональных данных
  • Уважение прав пользователей
  • Обеспечение безопасности личной информации

II. Собираемые персональные данные

А. При регистрации в приложении:

  • Логин пользователя
  • Адрес электронной почты

Б. Дополнительные данные, обрабатываемые при использовании функций приложения:

  • Доступ к контактам устройства — по вашему явному разрешению:
    • Используется для упрощения создания новых клиентов (контрагентов) в приложении SoloCRM на основе контактов, уже сохранённых в вашем устройстве.
    • Контакты используются только внутри приложения для отображения и создания записей клиентов по вашему выбору.
    • Мы не передаём ваши контакты третьим лицам и не используем их для рассылок или иной внешней коммуникации.
  • Доступ к микрофону устройства — по вашему явному разрешению:
    • Используется исключительно для записи голосовых заметок, которые вы самостоятельно создаёте и прикрепляете к заказам и клиентам в приложении.
    • Аудиозаписи хранятся в рамках вашего аккаунта и используются только для целей работы приложения (скорость и удобство фиксации информации).
    • Голосовые заметки не используются для распознавания речи сторонними сервисами без вашего отдельного согласия и не передаются третьим лицам в рекламных целях.

В. Данные, которые НЕ собираются автоматически:

  • IP-адрес
  • Журналы (логи) использования приложения в привязке к вашей личности

Г. Обработка ваших персональных данных осуществляется на основании:

  • Вашего добровольного согласия, предоставляемого при регистрации и/или при выдаче разрешений на доступ к функциям устройства
  • Необходимости исполнения договора (Пользовательского соглашения)
  • Закона Республики Казахстан «О персональных данных и их защите»

III. Цели обработки персональных данных

А. Основные цели:

  • Предоставление функционала приложения
  • Персонализация пользовательского опыта
  • Коммуникация с пользователем по вопросам работы сервиса
  • Улучшение качества сервиса

IV. Защита персональных данных

А. Технические меры защиты:

  • Шифрование данных с использованием современных алгоритмов
  • Использование SSL/TLS для передачи данных
  • Многофакторная защита базы данных
  • Шифрование данных на уровне базы данных

Б. Ограничения доступа:

  • Строго ограниченный доступ к персональным данным
  • Защита базы данных в несколько этапов

В. Срок хранения персональных данных:

  • В течение всего срока действия аккаунта
  • В случае удаления аккаунта персональные данные удаляются незамедлительно

V. Права пользователя

А. Пользователь имеет право:

  • Получать информацию о своих персональных данных
  • Удалить аккаунт
  • Отзывать согласие на обработку данных путём удаления аккаунта

Б. Удаление аккаунта:

  • Полное и безвозвратное удаление всех персональных данных
  • Невозможность восстановления после подтверждения

VI. Политика использования cookies

А. Минимальное использование cookies:

  • Только для аутентификации
  • Сохранение пользовательских настроек

VII. Передача данных третьим лицам

А. Принципы:

  • Запрет продажи персональных данных
  • Отсутствие передачи данных без согласия пользователя
  • Соблюдение законодательства Республики Казахстан, а также международных нормативно-правовых актов, ратифицированных Республикой Казахстан

VIII. Использование разрешений устройства (микрофон, контакты и др.)

Все разрешения на доступ к функциям устройства (таким как контакты, микрофон и др.) запрашиваются у пользователя в явной форме операционной системой устройства. Вы можете в любой момент отозвать выданные разрешения через настройки устройства, однако это может ограничить часть функционала приложения (например, создание клиентов из контактов или запись голосовых заметок).

IX. Изменение политики конфиденциальности

А. Порядок внесения изменений:

  • Актуальная версия всегда доступна в приложении и по адресу данной веб‑страницы
  • Возможность уведомления пользователей о существенных изменениях посредством внутриприложечных уведомлений или электронной почты
